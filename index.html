The Problem

Cognitive load isn't static.
Productivity tools are.

People with ADHD don't have a fixed attention deficit — they experience variability in cognitive control that shifts with task type, time of day, and mental state. Current tools can't see this.

8%
of people worldwide are affected by ADHD. For many, the condition continues well into adulthood and professional life.

234

The Core Gap
A person might succeed on a complex task in the morning and completely stall on an identical task after hours of context switching. Calendars and to-do apps treat every user the same at every moment — they cannot notice, cannot adapt, and cannot help.
Our Solution
CogniFlow fuses task-level complexity scores from an LLM with real-time behavioral signals from a standard webcam to produce a continuous Abandonment Risk Score — no special hardware required.
How It Works

A three-stage pipeline

Each stage contributes complementary signals. Task features capture what a user is doing; behavioral features capture how they're doing right now. Fusion makes the prediction meaningful.

01
LLaMA-3.1-8B-Instruct
Semantic Task Analysis
Each O*NET task description is fed to LLaMA-3 with a fixed ADHD-aware system prompt. The model extracts structured cognitive load features with 100% parse success across 400 tasks (3.9s/task on T4 GPU).
complexity 1–5 step_count priority_encoded
02
YOLOv8n-Pose
Behavioral Signal Extraction
17 body keypoints extracted from a standard webcam at 40.3 FPS. Five face-region keypoints produce three scalar signals per frame. A 120-second session window aggregates behavioral features.
avg_gaze avg_head_pose avg_eye_openness gaze_variance
03
XGBoost Classifier
Multimodal Fusion
A 7-dimensional feature vector is fused in an XGBoost classifier (200 estimators, depth 4, lr 0.05). Soft probabilistic labeling creates a gradual decision boundary rather than a hard threshold.
7-dim input risk ∈ [0,1] threshold 0.5
04
SHAP TreeExplainer
Live Explainability
SHAP force values overlaid directly on the webcam feed in real time. Skeleton mesh changes color — green when safe, orange at moderate risk, red at risk — with per-feature contribution bars visible to the user.
green / orange / red per-feature SHAP real-time overlay

Discussion

Key Findings

What the results mean — and what they don't. Honest interpretation matters more than inflated claims.

01
Fusion outperforms either modality alone
A focused person can handle a hard task just fine. A distracted person on a simple task may not need any intervention. It is the combination of task complexity and behavioral signals that tells you something meaningful about abandonment risk.
02
AUC of 0.958 — with an important caveat
Training labels are derived from a soft probabilistic rule on simulated behavioral data, not real-world recordings of professionals abandoning tasks. The model predicts the label rule very well — not verified real abandonment with 95% accuracy.
03
Gaze variance is the key behavioral signal
Only gaze variance reached statistical significance on DAiSEE (p=0.0044). Static gaze direction provides almost no information for this application. Future systems should prioritize temporal variability features over mean-based measures.
04
SHAP transparency changes how the tool feels
A system that says "you are at risk" is easy to ignore. A system that says "your gaze has been wandering more in the last two minutes" gives users something actionable. For ADHD users, transparency isn't optional — it's core to trust.
What's Next

Open questions & next steps

The pipeline is end-to-end functional. The next phase is about grounding it in real-world data and real users.

📋
Collect real abandonment data
Even 20–30 professional work sessions with ADHD participants, logging explicit task-switches and gives-up, would allow meaningful validation of whether the model's predictions match real behavior.
🎯
Per-user personalization
What counts as high gaze variance for one person may be their normal baseline. A simple 5-minute daily calibration recording could significantly improve both precision and user trust.
🧪
Evaluate with actual ADHD users
Validate in professional settings with individuals diagnosed with ADHD to confirm that SHAP explanations are actionable, trusted, and useful — not just technically coherent in testing.
